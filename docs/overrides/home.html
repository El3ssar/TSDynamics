Answers you can inspect

Measure stability, chaos, recurrence and attractor geometry. Results carry their settings and provide plots. Each analysis explains its supported inputs and the assumptions behind the answer.

From equations to a result you can see

The same workflow carries through the library: choose a model, run it, plot the trajectory, then ask a dynamical question.

{% filter tsd_highlight("python") %} import tsdynamics as ts model = ts.systems.Lorenz(ic=[1, 1, 1]) trajectory = model.run(final_time=100, dt=0.01) ts.plot(trajectory).save("lorenz.png") spectrum = ts.analysis.lyapunov_spectrum( model, final_time=500, dt=0.05 ) print(spectrum) print(spectrum.kaplan_yorke) {% endfilter %}
